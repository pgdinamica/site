Programe em Python online sem precisar de instalação

![](/assets/blog/como-usar-o-google-colab-para-analisar-dados/img-1.jpeg)

Neste vídeo, a Kizzy mostra como você pode utilizar a plataforma Google Colab para rodar seu código Python e analisar dados sem instalar nada em seu computador. Essa plataforma, hospedada em servidores da Google, oferece alguma conveniências como diversos pacotes para análise de dados já pré instalados e acesso ao poder computacional de máquinas mais poderosas, inclusive com possibilidade de uso de GPU para problemas de Machine Learning e Deep Learning.

https://www.youtube.com/watch?v=\_mIwsA2ddSc

Essa é uma alternativa interessante para quem tem dificuldades em executar o Jupyter Notebook na própria máquina ou gostaria de ter seu código acessível online para compartilhamento ou execução a partir de múltiplos lugares diferentes. Dessa vez, você vai aprender a importar ou criar um notebook do zero, acessar dados armazenados no seu Google Drive, instalar novos pacotes se você precisar, além de, é claro, executar seu código Python para resolver problemas! Rode Python na nuvem!
