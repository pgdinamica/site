## Sobre esta aula

Dado e informação são a mesma coisa? Nesta aula de abertura, você vai entender a diferença entre os dois conceitos e por que extrair informação de grandes volumes de dados só é possível com a ajuda do computador.

Também vamos conhecer **portais de dados abertos** — sites que disponibilizam dados para serem usados e redistribuídos livremente — e apresentar o conjunto de dados que vamos analisar ao longo do curso: os **microdados do ENEM**.

## O que você vai aprender

- A diferença entre dado e informação
- O que são dados abertos e por que eles são ideais para estudar
- Onde encontrar conjuntos de dados (datasets)
- O que são os microdados do ENEM
