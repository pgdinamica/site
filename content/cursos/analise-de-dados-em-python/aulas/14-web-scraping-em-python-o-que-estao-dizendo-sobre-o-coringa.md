## Sobre esta aula

O que as críticas diziam sobre o filme *Coringa*? Nesta aula, você vai coletar as críticas do site Rotten Tomatoes com **web scraping** e transformá-las em uma **nuvem de palavras** no formato da máscara do personagem — passando por processamento de linguagem natural e visualização de dados.

## O que você vai aprender

- Como fazer web scraping com o Beautiful Soup e salvar os dados em CSV
- Como tokenizar textos e remover stopwords com o NLTK
- Como filtrar apenas os adjetivos com *POS tagging*
- Como gerar uma nuvem de palavras com máscara usando `wordcloud` e Matplotlib
- Como traduzir as palavras com o `googletrans`
