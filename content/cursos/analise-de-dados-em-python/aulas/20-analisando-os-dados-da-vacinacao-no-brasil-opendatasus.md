## Sobre esta aula

Nesta aula, você vai explorar os dados da **Campanha Nacional de Vacinação contra a COVID-19**, disponibilizados no OpenDATASUS. A base reúne o número de doses aplicadas por estado, município, período, gênero, faixa etária e tipo de vacina, além das coberturas vacinais — e é publicada de acordo com a Lei Geral de Proteção de Dados (LGPD).

## O que você vai aprender

- Como acessar os registros de vacinação no OpenDATASUS
- Como explorar uma base pública de saúde
