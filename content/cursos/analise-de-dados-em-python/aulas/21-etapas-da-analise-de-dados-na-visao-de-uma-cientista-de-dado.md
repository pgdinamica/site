## Sobre esta aula

Por onde começar uma análise de dados? É preciso ter as perguntas prontas? A ordem dos passos altera o resultado? Nesta aula, a Kizzy organiza o que aprendeu como cientista de dados em um **passo a passo para conduzir uma análise**, de acordo com o objetivo e as particularidades de cada conjunto de dados.

Você também vai conhecer modelos clássicos do processo, como o **CRISP-DM**, o **SEMMA** e o **KDD** — que, no fundo, têm o mesmo objetivo: extrair informação dos seus dados.

## O que você vai aprender

- As etapas de uma análise de dados
- Como formular boas perguntas sobre os dados
- O que são os modelos CRISP-DM, SEMMA e KDD
