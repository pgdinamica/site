## Sobre esta aula

Com as mudanças na API do Twitter, extrair tweets antigos ficou mais difícil — a API passou a permitir apenas os últimos 7 dias. Nesta aula, você vai conhecer uma alternativa: substituir o **Tweepy** pelo **snscrape** para fazer a raspagem dos tweets.

## O que você vai aprender

- As limitações atuais da API do Twitter
- Como extrair tweets com o snscrape
- Como organizar os tweets em um DataFrame
