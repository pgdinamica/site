## Sobre esta aula

O primeiro vídeo sobre extração de tweets no canal faz sucesso até hoje (Extraindo tweets com Python | Análise de dados ep. 15 - <https://youtu.be/RssGfmtyn4A> - mas devido à atualização na API do Twitter alguns aspectos mudaram, por exemplo, as restrições na extração de tweets antigos. Atualmente a API só permite 7 dias, por essa razão nesse vídeo a Kizzy apresenta uma alternativa para essas extrações, substituindo o uso do Tweepy pelo Snscrape Twitter.
