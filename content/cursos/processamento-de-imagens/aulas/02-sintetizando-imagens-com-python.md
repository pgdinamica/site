## Sobre esta aula

Com a ideia de imagem digital em mãos, nesta aula você vai **criar imagens sintéticas**: usando a biblioteca **Pillow (PIL)** e um pouco de matemática — como matrizes —, vamos escrever em Python o código que pinta cada pixel da imagem.

Cada pixel armazena uma cor, representada por três valores num sistema de coordenadas — algo que vamos entender melhor na aula sobre cores no RGB. Com dedicação e criatividade, desenhar pixel a pixel permite construir aplicações sofisticadas, como a [animação de Dia dos Namorados](/cursos/processamento-de-imagens/aulas/programando-uma-animacao-de-dia-dos-namorados/) do fim do curso.

**Desafio:** escreva um programa que sintetize a bandeira do Brasil.

## O que você vai aprender

- Como criar uma imagem do zero com a Pillow
- Como pintar pixels a partir de fórmulas matemáticas
- Como a cor de cada pixel é representada
