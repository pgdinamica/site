## Sobre esta aula

Depois de estudar os filtros de forma geral, começamos pelos filtros específicos. Nesta aula, você vai implementar o **filtro box** (caixa), que provoca um efeito de **borramento** na imagem.

O filtro box é um filtro convolucional — uma categoria muito importante para entender as imagens digitais e as aplicações de visão computacional. Ele é um dos mais simples de compreender, porque todos os pesos do seu núcleo são iguais.

## O que você vai aprender

- O que é um filtro convolucional e o seu núcleo
- Como implementar o filtro box em Python
