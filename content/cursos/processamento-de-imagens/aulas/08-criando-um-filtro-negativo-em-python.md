## Sobre esta aula

Como fazer o "meme invertido"? Nesta aula, você vai escrever um programa em Python que transforma fotos em **negativo** e escreve sobre elas uma mensagem contrária à original — por exemplo, transformando o Programação Dinâmica em "Programação Estática".

Vamos abrir imagens com a biblioteca Pillow, calcular o filtro negativo invertendo a cor de cada pixel e escrever texto na imagem com o módulo `ImageDraw`. Com isso, você pode aplicar o efeito nas suas próprias fotos ou até criar um serviço que gere memes a partir de uma mensagem digitada.

## O que você vai aprender

- Como inverter as cores de uma imagem pixel a pixel
- Como escrever texto em uma imagem com o `ImageDraw`
