## Sobre esta aula

Que tal programar uma surpresa para quem você ama? Nesta aula, o Hallison mostra a animação que criou para a Kizzy num Dia dos Namorados: fotos dos dois aparecendo dentro de um coração que pulsa. Você vai aprender a criar uma **animação quadro a quadro** com técnicas de processamento de imagens, na linguagem Julia.

## O que você vai aprender

- Como representar curvas no plano cartesiano
- Como selecionar os pixels no interior de uma curva
- Como construir máscaras binárias para separar fundo e imagem principal
- Como gerar quadros de animação em uma taxa estável
- Como acelerar e mudar a escala do coração para criar o efeito de batimento
