## Sobre esta aula

Nesta primeira aula, revisamos os conceitos que você precisa para começar: o que é um **banco de dados**, o que são os **sistemas gerenciadores de bancos de dados (SGBDs)** e o que é a linguagem **SQL** (*Structured Query Language*), usada para consultar bancos de dados relacionais — aqueles organizados em tabelas.

Também apresentamos o ambiente de aprendizado do curso: o **BigQuery**, do Google Cloud, com as bases públicas tratadas pela **Base dos Dados**.

## O que você vai aprender

- O que são bancos de dados relacionais e SGBDs
- O que é SQL e para que serve
- Como será o ambiente de prática do curso
