## Sobre esta aula

Uma aula bônus e rápida para você dar os primeiros passos no **BigQuery**, o ambiente onde vamos praticar SQL durante o curso: como acessar o console do Google Cloud, encontrar as bases públicas da Base dos Dados e executar sua primeira consulta.
