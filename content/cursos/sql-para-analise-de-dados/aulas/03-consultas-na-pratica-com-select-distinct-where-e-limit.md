## Sobre esta aula

Hora de escrever as primeiras consultas. Nesta aula, você vai aprender a estrutura básica de uma consulta SQL: selecionar colunas, escolher a tabela, filtrar linhas, remover duplicatas e limitar o número de resultados.

## O que você vai aprender

- `SELECT` e `FROM`
- Filtros com `WHERE`, `AND` e `OR`
- `DISTINCT` para valores únicos
- `LIMIT` para limitar os resultados
