## Sobre esta aula

Nesta aula, você vai ordenar os resultados das consultas e conhecer novas formas de filtrar os dados: por listas de valores, por intervalos e por padrões de texto. No final, há um desafio para praticar.

## O que você vai aprender

- Ordenar resultados com `ORDER BY`
- Negar condições com `NOT`
- Filtrar intervalos com `BETWEEN`
- Filtrar listas de valores com `IN`
- Buscar padrões de texto com `LIKE`
