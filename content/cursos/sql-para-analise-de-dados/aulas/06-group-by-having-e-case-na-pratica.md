## Sobre esta aula

Nesta aula, você vai agrupar os resultados com `GROUP BY`, filtrar grupos com `HAVING` e criar categorias com a estrutura `CASE ... WHEN ... THEN`, praticando com os dados das eleições brasileiras do TSE.

## O que você vai aprender

- Agrupar resultados com `GROUP BY`
- Filtrar grupos com `HAVING` (e a diferença para o `WHERE`)
- Criar categorias com `CASE`
