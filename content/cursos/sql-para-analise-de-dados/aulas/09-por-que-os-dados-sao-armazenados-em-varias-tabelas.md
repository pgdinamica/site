## Sobre esta aula

Antes de aprender a combinar tabelas, fazemos uma pausa para responder: **por que os bancos de dados guardam as informações em várias tabelas**, em vez de um único "tabelão"? Você vai entender as propriedades dos bancos relacionais, os objetivos da **normalização** e os problemas de trabalhar com uma tabela só.

## O que você vai aprender

- Por que bancos relacionais usam várias tabelas
- As propriedades dos bancos de dados relacionais
- Os objetivos da normalização de dados
- Os problemas de uma tabela única
