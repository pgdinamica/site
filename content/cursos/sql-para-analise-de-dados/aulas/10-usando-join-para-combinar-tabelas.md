## Sobre esta aula

Nesta aula, começamos o estudo das **junções**. O `JOIN` combina duas tabelas a partir de uma chave ou de um valor em comum entre elas — e é uma das ferramentas mais importantes de quem trabalha com dados.

## O que você vai aprender

- Para que serve o `JOIN`
- Como combinar duas tabelas por uma coluna em comum
