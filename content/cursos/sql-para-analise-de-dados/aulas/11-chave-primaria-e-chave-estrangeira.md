## Sobre esta aula

O que liga uma tabela à outra? Nesta aula, você vai entender a intuição por trás do conceito de **chave** e a diferença entre **chave primária** e **chave estrangeira** — a base para fazer junções com segurança.

## O que você vai aprender

- O que é uma chave primária
- O que é uma chave estrangeira
- Como as chaves relacionam as tabelas
