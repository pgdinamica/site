## Sobre esta aula

Uma consulta escrita para um banco de dados funciona em todos os outros? Nesta aula, você vai entender as diferenças entre os dialetos de SQL e a **ordem em que o banco processa** cada parte de uma consulta — o que explica muitos erros comuns.
