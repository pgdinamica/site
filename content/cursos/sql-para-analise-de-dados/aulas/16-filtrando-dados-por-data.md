## Sobre esta aula

Saber lidar com datas é essencial na análise de dados. Nesta aula, você vai conhecer os **tipos de dados** do BigQuery e do SQL padrão e praticar as principais **funções de data**, usando os dados de filiações partidárias do TSE disponibilizados pela Base dos Dados.

## O que você vai aprender

- Os tipos de dados do SQL padrão, em especial o `DATE`
- Funções de data no BigQuery

## Material de apoio

- [Dados: eleições brasileiras (TSE)](https://basedosdados.org/dataset/br-tse-eleicoes)
